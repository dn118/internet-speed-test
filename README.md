# Замер скорости скачивания

Консольный скрипт делает 10 последовательных GET-запросов по указанному URL. Каждый ответ читается до конца порциями по 64 КиБ.

## Запуск

Нужен Python 3.8 или новее. Сторонние зависимости не нужны.

В каталоге репозитория выполните команду, подставив URL файла:

```bash
python3 speed_test.py "https://example.com/large-image.jpg"
```

На Windows можно заменить `python3` на `py -3`. Для замера подойдёт прямая ссылка на файл размером в несколько мегабайт. Скрипт скачает его десять раз.

## Результат

- **Average request time** — среднее время одного запроса в миллисекундах, от начала запроса до чтения всего тела ответа.
- **Total downloaded** — суммарный размер тел ответов в байтах.
- **Download speed** — скорость в **Мбит/с (Mbps)**. Суммарное число байтов умножается на 8 и делится на суммарное время запросов в секундах и на 1 000 000.

Скорость зависит от выбранного сервера, маршрута до него и времени установки соединения. При сетевой или HTTP-ошибке скрипт сообщает номер запроса, завершает замер и возвращает код 1. Тайм-аут отдельной блокирующей сетевой операции составляет 30 секунд.
